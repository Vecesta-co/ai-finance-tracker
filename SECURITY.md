# Security Policy

## Supported Versions
| Version | Supported |
|---------|-----------|
| 1.x     | ✅        |

## Zero-Knowledge Local Architecture
- `ai-finance-tracker` never prompts for or stores bank login credentials or account passwords.
- All transaction records and budgets reside in a local SQLite file on your filesystem.
- No telemetry, analytics, or background tracking pixels.

## Reporting a Vulnerability
Email **vecesta.co@gmail.com**. We respond within 48 hours.
